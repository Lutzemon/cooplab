# Feedback

This repository is for project information and public feedback. The playable
build and implementation are not published yet, so code contributions and
public playtesting are not open at this stage.

Use Issues for questions, ideas and corrections to the documentation. There
is currently no public test sign-up; please do not post requests for private
invitations or server access.

Keep account details, raw logs, saved games, invitation codes and private server
addresses out of public issues and attachments. Approved testers should share
their detailed playtest notes through their existing private channel.
